# Mermaid Boost (`mermaid-boost`)

Smart compact sizing, **7 Theme Groups (29 Themes)**, and interactive zoom/export controls for Obsidian Mermaid diagrams.

## ✨ 7 Theme Groups · 29 Themes (1:1 HTML Showcase Match)

1. **Styled (4)**
   - **`claude` (`Claude` — cream, clay, serif)**: `#faf9f5` canvas, `#f0eee6` fill, `#c6613f` clay border, `rx: 12px`, `Georgia` serif.
   - **`notion` (`Notion` — clean, soft grey)**: `#ffffff` canvas, `#f7f6f3` fill, `#dfdedb` border, `#e7f3f8` clusters, `rx: 6px`.
   - **`notion-dark` (`Notion dark` — charcoal)**: `#191919` canvas, `#252525` fill, `#3b3b3b` border, `#e6e6e6` text, `rx: 6px`.
   - **`handcrafted` (`Handcrafted` — paper, marker, wobbly lines)**: `#fdf6e3` canvas, `#fff3b0` marker fill, `#2b2b2b` ink border, `rx: 12px`, cursive font + `#mb-wobble` SVG displacement filter.
2. **Developer (4)**
   - **`nord` (`Nord` — icy blue-grey)**
   - **`dracula` (`Dracula` — purple and pink)**
   - **`solarized` (`Solarized` — warm beige, teal)**
   - **`gruvbox` (`Gruvbox` — retro earthy dark)**
3. **Paper & print (4)**
   - **`blueprint` (`Blueprint` — white on blue, `20px 20px` technical grid)**
   - **`newspaper` (`Newspaper` — ink on newsprint)**
   - **`academic` (`Academic` — greyscale for papers)**
   - **`kraft-paper` (`Kraft paper` — brown stock, stamped)**
4. **Retro & playful (5)**
   - **`chalkboard` (`Chalkboard` — chalk on green + `#mb-wobble` filter)**
   - **`terminal-crt` (`Terminal / CRT` — phosphor green + `#33ff66` glow)**
   - **`game-boy` (`Game Boy` — four greens)**
   - **`synthwave` (`Synthwave` — neon on purple + `#ff2e97` pink glow)**
   - **`sticky-notes` (`Sticky notes` — cork board dot pattern + yellow/pink/green sticky notes)**
5. **Brand-inspired (5)**
   - **`github-light` (`GitHub light` — white, grey, green)**
   - **`github-dark` (`GitHub dark` — dimmed dark)**
   - **`linear` (`Linear` — near-black, violet glow)**
   - **`stripe` (`Stripe` — white, indigo)**
   - **`metro-map` (`Metro map` — bold `4px` station nodes + `6px` red/blue/green transit lines)**
6. **Functional (3)**
   - **`high-contrast` (`High contrast` — black and white, thick `3px` strokes)**
   - **`colorblind-safe` (`Colorblind-safe` — Okabe-Ito 6-color palette)**
   - **`mono-accent` (`Mono + one accent` — grey with orange `#e8590c` key path)**
7. **Built-in (4)**
   - **`builtin-default` (`default`)**, **`builtin-neutral` (`neutral`)**, **`builtin-dark` (`dark`)**, **`builtin-forest` (`forest`)**

## 📦 Installation

Copy `manifest.json`, `main.js`, and `styles.css` to `<Vault>/.obsidian/plugins/mermaid-boost/` and enable **Mermaid Boost** in **Obsidian Settings → Community Plugins**.
